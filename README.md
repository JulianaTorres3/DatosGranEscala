# DatosGranEscala
# Procesamiento de Datos — Taller 1

## Introducción

Este repositorio contiene el desarrollo del **Taller 1 de la asignatura Procesamiento de Datos**.

En este taller se trabajan conceptos básicos de programación en Python que sirven como base para el manejo y procesamiento de datos. Se realizan diferentes ejercicios para aprender a trabajar con estructuras de datos, controlar el flujo de un programa, crear funciones y conocer los conceptos básicos de clases y objetos.

## Objetivo

Aprender y aplicar conceptos fundamentales de Python para poder almacenar, organizar, manipular y procesar información.

## Temas trabajados

* **Cadenas:** indexación, slicing, stride, concatenación y secuencias de escape.
* **Listas:** creación, indexación, modificación, copia y clonación.
* **Tuplas:** características, indexación y slicing.
* **Conjuntos:** creación y operaciones como unión, intersección y diferencia.
* **Diccionarios:** claves, valores y operaciones básicas.
* **Condiciones:** `if`, `elif`, `else` y operadores lógicos.
* **Bucles:** `for`, `while` y `range()`.
* **Funciones:** creación de funciones, parámetros, argumentos, valores predeterminados y ámbito de variables.
* **Clases y objetos:** clases, instancias, atributos y métodos.

## Herramientas utilizadas

* Python
* Google Colab
* GitHub

## Conclusión

Este taller permitió conocer las bases de Python y practicar diferentes herramientas para trabajar con información. Los temas vistos servirán como base para continuar aprendiendo sobre procesamiento y análisis de datos durante la asignatura.
